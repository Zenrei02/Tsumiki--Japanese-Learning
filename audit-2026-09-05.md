
The engagement module is authored at the repo root and not yet spliced, so it is outside

*the modules that exist right now are all the modules there are.* It will catch
`engagement-v1` at splice time, which is after the module is live in a build; catching it
at authoring time is one glob wider.

`stroke-data-v1` **is** written — by `tsumiki-app/src/lib/strokeEngine.jsx:180`, which the
scan also does not cover. One cause, two symptoms: a false all-clear on a real missing
key, and a false suspicion on a live one.

**Proposed (mechanical, no Japanese content):** widen `written_keys()` to
`tsumiki-app/src/**/*.{jsx,js}` plus the root `*-module.jsx` authoring files, and prove it

on `n5-progress-v1`. `tsumiki-last-module` is already in `IGNORE` and stays there.

that qualifies.
