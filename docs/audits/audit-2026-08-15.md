## Appendix — how item 4 went, because two things are worth carrying

**The probe caught the first draft of the lesson, and that is the whole argument for the probe.**
`sb-suruverbs` was written, placed, and compiled — and `curriculum-gap-audit.py` still reported `word formation: noun + する` **MISSING**. The lesson had buried the rule in a metaphor: *"It is the machine Japanese uses to turn nouns into verbs."* True, well-written, and it never states the formation in a shape a learner can apply.

The tempting move was to loosen the regex until it matched the prose. **That would have been fitting the test to the answer** — the same error the probe's own comment block warns about, one file up. Instead the lesson changed: `build` now opens *"Noun + する makes a verb — textbooks call these サ変動詞, or just する-verbs."* Better writing, and an honest pass.

Worth stating plainly: the check was retuned in item 1 and then immediately used in item 4 to reject work. A probe that only ever confirms is not doing anything.

**Every green result here was proven capable of going red first.**
Not a flourish — §2 records the compile check that reported all seven modules failing for a flag error, with a negative control that "failed correctly" for the same wrong reason. So: the gap audit was re-run against a fixture with `sb-suruverbs` removed (exit 1, same gap); `esbuild` against a garbage file and a truncated real module (both exit 1); the smoke run took a bundle built after the edit, with the freshness gate live.

**What is NOT verified: the Japanese.** `sb-suruverbs` is AI-authored and has not been read by a native. It is in `rc1`'s `covers`, so its claims can surface in Checkpoint 1 quiz generation — a wider blast radius than a lesson body alone. The four riskiest claims are itemised in Batch E; the を alternation (`勉強をする` allowed, `日本語を勉強をする` barred on one-を-per-clause) is the one most worth a sceptical read.

**One thing I got wrong and caught:** while editing `reviewer-content-batches-v1.md` I corrupted a character in text I was only meant to preserve — `難しいですね` became `難しいですне` with a Cyrillic *не*. In a file that is mostly Japanese, that class of typo is close to invisible on review, so the sweep is worth repeating after any bulk edit to these documents.
