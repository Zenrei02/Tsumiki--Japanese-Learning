WHAT THIS IS FOR

Board 11's wizard answers where the learner is starting from, then drops them on Home with nothing said about the room, the journey, じしょ or the menu. These three slides say it once, before the first block — and nothing about any single section, which waits for that section's own deck (row 2).

DECIDED

  • Slides, not a tour of the live Home (Lloyd, Oct 16 10:04). Board 13's first attempt — six stops with a scrim on the real Home — is superseded.
  • Animated from the app's own parts, not video. Accepted in principle: a video goes stale every time a screen changes, and is heavy on a phone.
  • One red thing per slide, as everywhere: Next. The last slide's red button is Start and lands on Home with focus on the red card.
  • Dots, not "1 of 3". No counts.

OPEN — LLOYD'S CALL

  • The shape itself: three universal slides, then 2–3 per section on first open. Approve or amend before anything is built.
  • All English copy — every line marked DRAFT.
  • U1's promise. "Every bit of study is a block" describes the tower that is wanted but not built yet. If the intro ships first, U1 says only what the block notice already does today.
  • Skip on slide one only (as drawn), or on every slide.

BEHAVIOUR (PROPOSED)

  • Swipe or Next/Back. Skip on U1 marks the whole universal deck seen.
  • Seen once per account, on the welcome's mechanism: a flag in KEYS with a constant value, so a sign-in never asks "which copy?" about it.
  • Replayable — the universal deck from the menu, each section deck from a ? in that section's header.
  • Reduced motion: the end state of each animation, no movement.
