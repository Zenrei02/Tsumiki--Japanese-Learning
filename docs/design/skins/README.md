# tsumiki — Home skins (candidates for unlock in the Room / shop)

Standalone previews of the four alternative Home looks from the Sep 2026 design rework.
Open any file in a browser. Each keeps the same structure as the shipped Home
(header, scene band, "next on your path" card, module grid, Room / Dictionary buttons)
so a skin is a restyle, not a relayout. None are wired to the app.

| File | Skin | Notes |
|---|---|---|
| skin-ink-and-washi.html | B · Ink and washi | Plain paper, sumi-ink scene, white tiles with a coloured seal. Cheapest to build. |
| skin-engawa-garden.html | C · Engawa garden | Veranda view, cedar header, modules as stepping stones. |
| skin-tokyo-transit.html | D · Tokyo transit | Station-sign header, platform scene, modules as line roundels, ticket card. |
| skin-neon-tokyo.html | E · Neon Tokyo | Night alley, katakana neon, glass cards, glowing tube buttons. Module colours remapped to neon hues. |

The base day mode and the "Dusk lantern" dark mode live on the design canvas
(claude.ai artifacts → "tsumiki — tatami room rework").
Brand rules hold in every skin: lowercase wordmark, つ glyph, 直し for the Checker, no counts.
